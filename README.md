# Computational Genetics Research — Missense VUS Investigation

Reproducible computational pipeline for investigating **missense variants of uncertain
significance (VUS)** in a selected disease-associated gene using public genetic databases
(ClinVar, gnomAD, Ensembl) and computational prediction tools.

## IMPORTANT — scope disclaimer

This is an **academic/research** project, **not** a clinical diagnostic workflow. No variant
is ever labeled definitively pathogenic or benign from computational analysis alone. We
identify *evidence patterns* and *candidates for further investigation*.

## Reproducibility principles

1. Raw data is **immutable**; every transformation writes a *new* file.
2. Every downloaded dataset is logged with URL, access date, version, and checksum.
3. Parameters live in `config/config.yaml`, not hard-coded in code.
4. Every figure/table is generated by a script (no manual edits).
5. Two independent sources are cross-checked wherever practical (e.g. ClinVar protein
   change vs. VEP annotation).
