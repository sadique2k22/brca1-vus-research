# Reproducibility Guide

A researcher with a fresh Ubuntu environment (or a resource-constrained device such as Android/Termux
via proot-distro) can follow this guide. Heavy computation is intended for GitHub Actions; only
lightweight local steps are required to inspect or re-derive results.

## 1. Requirements

- Python ≥ 3.12
- `git`, `curl`
- No Docker, VEP cache, bcftools, or whole-genome downloads are required.

## 2. Environment setup (local, lightweight)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## 3. Repository setup

```bash
git clone https://github.com/sadique2k22/brca1-vus-research.git
cd brca1-vus-research
```

## 4. Configuration

All parameters are in `config/config.yaml` (pipeline), `configs/analysis_config.yaml` (thresholds),
and `configs/phase7_cohort.yaml` (cohort rules). These are frozen.

## 5. Pipeline execution

**GitHub Actions (recommended, heavy):** push to `main` (the workflow re-runs only when
`src/`, `scripts/`, `configs/`, `config/`, `tests/`, `requirements.txt`, or `data/raw/` change), or
trigger manually via *Actions → pipeline → Run workflow*.

**Local (lightweight — does NOT re-download data):** the derived datasets and result tables are
already committed; re-running analysis scripts locally reads them read-only:

```bash
python scripts/phase5_analysis.py     # statistics + figures (requires results/tables inputs)
python scripts/phase12_supplementary.py   # regenerate supplementary tables
```

The full end-to-end data-acquisition pipeline (`download → parse → filter → normalize → annotate`)
re-fetches 442 MB (ClinVar) + 636 MB (REVEL) and is intended for CI, not local use.

## 6. Test execution

```bash
python -m unittest discover -s tests
```

## 7. Figure generation

Figures are generated by `src/figures.py` (SVG + 300-dpi PNG) as part of `scripts/phase5_analysis.py`
and `scripts/phase7_cohort.py`. They are committed under `results/figures/` and `manuscript/figures/`.

## 8. Manuscript generation

The manuscript is a static Markdown file (`manuscript/manuscript.md`); it is not generated by code.

## 9. GitHub Actions workflow

`.github/workflows/pipeline.yml` runs: validate config → tests → download (cached) → parse → filter →
normalize → annotate → Phase 5–9 → audit → commit results + upload artifacts.

## 10. Expected outputs

`results/tables/` (18 tables), `results/figures/` (16 figures × SVG+PNG), `results/reports/`
(34 reports), `manuscript/manuscript.md`.

## 11. Checksum verification

```bash
sha256sum data/processed/brca1_vus_missense_annotated.tsv
# expect 7afe54db14718bcc612531325fb18ade9c1ae1a50aa4a0a0237cdee3708a2797
```

## 12. Troubleshooting

- **Missing large downloads:** the raw `.gz`/`.zip` are not committed; re-run the CI pipeline to
  re-fetch them (cached + sha256-verified).
- **Rate-limited API calls:** all API clients cache to `data/intermediate/*_cache/` and retry with
  backoff; a re-run resumes without re-requesting cached records.
